# fcm-device-registration Specification

## Purpose
Synchronizes FCM registration tokens generated by the mobile client with the Testpress backend server to identify target device routing.
## Requirements
### Requirement: Device Registration Request
The system SHALL send the current FCM registration token to the Testpress backend endpoint on startup or login.

#### Scenario: Syncing token to server
- **WHEN** a user is authenticated and retrieves a valid FCM token
- **THEN** the system MUST perform a POST request to `/api/v2.2/devices/register/` containing the registration ID and device ID.
