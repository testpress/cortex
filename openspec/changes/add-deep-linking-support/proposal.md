## Why

When users tap on push notifications or open web links generated by the Testpress backend (such as `/dashboard`, `/courses/:id/contents/:id`, `/exams/chapter_content/:id`, `/p/:slug`, or `/products/:slug`), Cortex currently passes the raw URL path directly to `GoRouter.push(path)`.

Because internal GoRouter paths differ from server-generated web paths (for example, the dashboard is located at `/home` instead of `/dashboard`, and lessons are located at `/study/lesson/:id` rather than `/courses/:id/contents/:id`), GoRouter fails with `GoException: no routes for location: ...` and displays a "Page Not Found" error.

The native Android app solved this via a dedicated `DeeplinkHandler.java` that parsed incoming URIs, extracted IDs and slugs from path segments, and dispatched them to their destination screens. Cortex requires a unified deep link resolver to normalize incoming notification and web URLs into valid GoRouter destinations.

## What Changes

- **DeepLinkHandler Utility**: Introduce a platform-neutral `DeepLinkHandler` in `packages/testpress` that parses and normalizes incoming URLs:
  - `/dashboard`, `/learn`, `/leaderboard` → `/home`
  - `/login` → `/login`
  - `/activate` → `/signup`
  - `/courses/:courseId/contents/:contentId` → `/study/lesson/:contentId`
  - `/exams/chapter_content/:contentId` → `/study/lesson/:contentId`
  - `/chapters/:chapterId/:contentId` → `/study/lesson/:contentId`
  - `/chapters/:chapterId` → `/study/course/:courseId/chapters/:chapterId`
  - `/products/:slug` or `/store/product/:slug` → `/store/product/:slug`
  - `/products` or `/store` → `/store`
  - `/exams` or `/exams/available` or `/exams/upcoming` or `/exams/history` → `/exams`
  - `/p/:slug` or `/posts/:slug` → `/home/discussions/forum/posts/:slug`
  - Unknown/unmatched paths → Gracefully fallback to `/home` instead of throwing an unhandled `GoException`.
- **Push Notification Integration**: Update `PushNotificationService._handleDeepLink` to route URLs through `DeepLinkHandler.resolve(url)`.
- **Query Parameter Safety**: Automatically strip query strings (such as `?content_detail_v2=true&use_htmx_for_partial_views=true`) before path resolution.
- **Automated Tests**: Comprehensive unit tests covering all URL patterns and fallback scenarios.

## Capabilities

### New Capabilities
- `deep-link-resolution`: Normalizes external web and push notification URLs into internal GoRouter routes, handling query parameters, path segment extraction, and graceful fallback routing.

### Modified Capabilities
- `fcm-integration`: Updates notification tap handling in `PushNotificationService` to invoke `DeepLinkHandler`.

## Impact

- `packages/testpress/lib/navigation/deep_link_handler.dart`: New URL parser and resolver.
- `packages/testpress/lib/providers/push_notification_service.dart`: Integrates `DeepLinkHandler`.
- `packages/testpress/test/navigation/deep_link_handler_test.dart`: Unit tests for URL mapping and edge cases.
