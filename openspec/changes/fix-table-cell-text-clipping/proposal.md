## Why

In `AppHtmlV2`, tables with inline heights or small row heights (typically generated by rich-text editors such as CKEditor or pasted from Microsoft Word/Excel) experience vertical text clipping on mobile. The text inside table cells has its top portion/ascenders cut off because native Flutter layout (`flutter_widget_from_html_core` via `HtmlTable`) applies tight height constraints and fixed cell padding that conflict with restrictive heights from incoming HTML markup.

## What Changes

- Sanitize table elements (`table`, `tr`, `td`, `th`) in `AppHtmlV2._sanitizeHtml()` to strip restrictive inline styling (`height`, `min-height`, `max-height`, `line-height`) and legacy HTML attributes (such as `height="..."`).
- Adjust `AppHtmlV2.customStylesBuilder` for table cells (`td`, `th`) to ensure intrinsic text height determines row height dynamically, preventing text clipping across varying font sizes and mobile screen resolutions.
- Add test coverage verifying that HTML tables with restrictive inline heights and legacy height attributes render without text clipping or layout overflow.

## Capabilities
