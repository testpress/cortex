## Context

Post notifications generated by the Testpress backend contain relative URLs in the form `/p/:slug` or `/posts/:slug`. Currently in `DeepLinkHandler.rules`, these are mapped to `/home/discussions/forum/posts/:slug`. When tapped, this invokes `ForumPostDetailScreen`, which queries the Discussions API (`/api/v2.5/discussions/<slug>/`), returning a 404 since announcements are separate entities managed under `/api/v3/posts/`.

## Decisions

### Decision 1: Use `/api/v3/posts/<slug>/` for Single Post Fetching with Short Link Support
- **Choice**: Invoke `GET /api/v3/posts/<slug>/?short_link=true` with fallback to standard slug query in `HttpDataSource`.
- **Rationale**: In the Testpress backend (`apps/api/v3/posts/views.py`), notifications generate short URLs (`/p/<short_code>`). Passing `?short_link=true` configures the backend view lookup field to `short_link`. Supporting fallback to standard slug query guarantees that both `/p/<short_code>` and `/posts/<slug>` URLs resolve accurately.

### Decision 2: Local SQLite Caching via Drift
- **Choice**: Store fetched posts into `PostsTable` via `PostsRepository.fetchPost(slug)` and watch with `watchPostBySlug(slug)`.
- **Rationale**: Adheres to the offline-first repository pattern used throughout the Cortex platform SDK (`packages/core`). Once fetched, post details remain accessible offline.

### Decision 3: Route Path Structure in GoRouter
- **Choice**: Register routes under `HomeRoutes` at `/home/posts` and `/home/posts/:slug`.
- **Rationale**: In the Cortex UI shell, announcements are presented from the Dashboard tab (`/home`). Registering `/home/posts/:slug` ensures the back-stack returns naturally to the home screen or announcements list.

### Decision 4: Rule Table Normalization
- **Choice**:
  - `/posts/:slug` → `/home/posts/:slug`
  - `/p/:slug` → `/home/posts/:slug`
  - `/posts` → `/home/posts`
  - `/p` → `/home/posts`
  - `/discussions/forum/posts/:slug` remains `/home/discussions/forum/posts/:slug`
- **Rationale**: Completely decouples blog posts / announcements from forum discussions, eliminating the "Discussion Not found" bug.
